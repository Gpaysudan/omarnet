# OMAR NET

واجهة Portfolio احترافية ثنائية اللغة لمهندس شبكات، مبنية بـ HTML + CSS + JavaScript فقط وجاهزة لـ GitHub Pages.

## المزايا
- العربية والإنجليزية بالكامل مع RTL/LTR.
- Dark / Light Mode مع حفظ الاختيار محليًا.
- PWA مع زر تثبيت ثابت في الشريط العلوي على الهاتف والكمبيوتر.
- Service Worker وملفات أيقونات 192/512 وMaskable.
- تصميم Responsive بطابع سوداني حديث.
- أقسام: الملف الشخصي، الخدمات، المشاريع، المهارات، الشهادات، والتواصل.
- نموذج تواصل يرسل تفاصيل الطلب مباشرة إلى WhatsApp.

## الصورة الشخصية
الصورة الحالية موجودة في `assets/profile.svg`. لاستبدالها بصورة حقيقية، ضع الصورة داخل `assets/` ثم غيّر `src` للصورة في `index.html`.

## النشر على GitHub Pages
ارفع محتويات هذا المجلد إلى جذر المستودع، ثم فعّل GitHub Pages من الفرع الرئيسي. جميع مسارات PWA نسبية ومتوافقة مع مستودعات GitHub Pages.
